🤖 What Is Predictive AI?

Predictive AI learns the characteristics of data classes and proposes a function that differentiates between them. It outputs a probability distribution indicating how likely the input data belongs to a given class.

📌 Example:

When feature X is present → probably Class A

When feature Y is present → probably Class B

⚠️ Why Isn't It 100% Accurate?

Due to the homogeneity of real-world data, predictive AI is rarely perfect. Some attributes of Class A also appear in Class B, and vice versa. This overlap creates uncertainty.

🎚️ The Role of the Threshold

A threshold must be set to determine the point at which a prediction switches from one class to another.

Setting the threshold is like defining an application's functional specifications — it should be done in collaboration with stakeholders.

Technical teams can quantify outcomes at different thresholds and advise on trade-offs, but the final decision must reflect core strategic objectives, risk tolerance, and constraints.

⚖️ The Trade-Off

If the threshold is too low → False Positives increase
A truly negative case is incorrectly predicted as positive.

If the threshold is too high → False Negatives increase
A truly positive case is incorrectly predicted as negative.

Depending on the use case, this trade-off can have vastly different implications.
